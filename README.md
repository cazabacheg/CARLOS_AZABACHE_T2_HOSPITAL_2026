# Hospital Vida Salud — Microservicios (Evaluación T2)

Plataforma administrativa hospitalaria académica basada en microservicios:
Spring Boot, Spring Cloud Gateway, Eureka, RabbitMQ, WebFlux y R2DBC (PostgreSQL), con integración continua en GitHub Actions.

> Proyecto académico. Todos los datos son ficticios.

Estado: **en construcción**. La documentación de diseño está en [`docs/documento-tecnico.md`](docs/documento-tecnico.md).
El README completo (arquitectura, requisitos, ejecución y pruebas) se completará al terminar la implementación.
